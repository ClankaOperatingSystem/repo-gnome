#+TITLE: Serving the maintainer

* Pull requests

- Prepare changes on a feature branch in the working copy.
- Push that branch and open a pull request for review.
- Never merge, or push to =master=; merging is the maintainer's decision.
- Never push a branch identical to its base: the forge closes its pull
  request.
