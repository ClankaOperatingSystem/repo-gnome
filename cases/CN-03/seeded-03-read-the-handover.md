#+TITLE: The scope contract

The directory a scope's configuration names in its =projects= key holds
its child projects. A scope with no configuration names none, so a
directory called =projects/= inside it is an ordinary directory of that
scope. No directory name marks a responsibility; its configuration does.
Before moving a scope or a mounted repository, read the handover of 9
March 2025 for what depended on a path when the grouping directories were
removed.
