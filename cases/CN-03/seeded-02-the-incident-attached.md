# Project review

## Read before writing

For the period since the last sealed review, read the project's file and
its brief, every event in its ledger, the commits and pull requests of
every repository the project's tasks name, and each file a next action
depends on.

Do not report a task's state from the project file alone. A task list can
be behind the work: the tower project's showed a migration as not started
on the day another session merged it.
