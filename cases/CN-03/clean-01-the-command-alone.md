# Wrap up

Update `journal.org` so the latest handover is unambiguous, including
when several entries share a date: `./bin/journal-entry 'Title' DATE <
BODY` adds the entry before the latest one and marks that one earlier,
changing nothing else. If closing again after publication, preserve a
short supplementary handover linking the earlier one.
