#+TITLE: Reading archived evidence

Use =archive-integrity fetch LINK= for a cited archived file, whether its
bytes are local or kept remotely. Replace the example with the citation's
file CID, or collection CID and member path. A collection CID alone names
a directory and cannot be fetched.
