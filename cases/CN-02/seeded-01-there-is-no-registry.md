#+TITLE: The scope contract

* When a project emerges

Creating the project's own Org file in the directory the configuration
names for its projects is the commitment. The file holds the outcome, the
next action, a review task with a date and the project's tasks.

There is no registry file. A scope's portfolio is the set of projects in
its projects directory together with those its configuration declares,
and a review lists them from there. Each project's own file is the one
authority for its state and next actions.
