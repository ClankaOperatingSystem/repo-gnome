# Tidy canon

The doctrine is in `references/doctrine/`, beside this file; its
policies are in `references/policies/`, one judgement each, and the
checks in `scripts/` answer three of them. Read the doctrine at the
start, so the clauses in force are the current ones. Do not work from
memory of them.

Run it when asked. It is heavy for a whole scope; a pass over one
document or one session's changes is light.

## Sequence

1. **Baseline.** Run the lint; its findings under CANON-2, CANON-7 and
   CANON-8 are the checks' answers. Count the scope's documents and words,
   leaving out archives, attics and underscore directories.
2. **Read the whole scope first**, then apply each judged policy in
   `references/policies/` to each document, as the policy's instructions
   say: report a finding only where the words can be quoted, and where a
   passage is ambiguous it complies.
3. **Propose by class.** Group the findings by clause, and put each class
   to the person with a sample in context and the rewrite the doctrine
   asks for. A ruling on a class authorises its repair wherever it
   recurs; a passage that does not fit the ruling comes back.
4. **Repair.** What leaves canon goes verbatim to where the scope keeps
   what has left canon, with the document and heading it came from. What
   is status becomes a task in the owning file. A rule with many homes
   keeps one and the rest link to it. A rule stays stated once, in the
   positive, in the present tense.
5. **Verify.** Run the lint again and the scope's link check, and compare
   the counts with the baseline.
6. **Report**, concisely: documents tended, one line each; passages moved
   out; tasks made; doubts not acted on.

## What stays

Present-tense statements of what a thing is, what it is for, how it works,
what to do and when. The reasons that change what the reader does. Where
things are. A real limit that affects use, stated once. A link to a record
the reader opens while doing the work. Task bodies.

## Containment

Work only inside the scope named. Change nothing in an archive. Commit
nothing; report what changed and let the person commit.
