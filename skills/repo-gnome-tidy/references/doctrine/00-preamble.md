# The canon doctrine

Standards for canon: the documents a repository maintains and reads to do
its work. Instructions files, methods, indexes, entrances, skills and the
pages of a project. They apply to whoever maintains those documents, human
and agent.

The files in this directory are joined in filename order into one
document. A model judging a policy is given that document, then the
policy's instructions. A person reads it as the standard that every
finding cites.

Each clause has an id, such as CANON-2, and a finding cites the id of the
clause it was raised under. An id is never reused, so the numbers have a
gap where a clause was retired.

A policy's header lists the clauses it judges. A clause no policy lists is
guidance, and no finding is raised under it.

Canon is judged as standing text, not as a change. A passage is reported
as it is found, whether or not the change under review added it.
